# Indicators

Open Indicators under Charts to browse the agent's indicator catalog.

## Built-in indicators

- Use SMA, EMA, RSI, MACD, Bollinger Bands, ATR, and ADX.
- Search the catalog and filter built-in or custom indicators.
- Read an indicator's description, interpretation, and source.
- Add indicators to a chart and adjust their inputs.
- Hide, reorder, or remove indicators on a chart.
- Choose the price pane or a separate pane in the indicator's advanced options.

Built-in source is read-only. Choose Copy to custom to make your own version.

## Custom indicators

- Create an indicator with a name, description, interpretation, and PineScript source.
- Preview it for an instrument, timeframe, and date range before saving.
- Inspect plots, signals, drawings, and warnings in the preview.
- Save changes as a new version and browse earlier versions.
- Give a sub-agent indicator tools if you want it to run indicators or help develop them.

Saving makes the new version current immediately. There is no separate publish
step. Preview and chart input overrides do not change the indicator's saved defaults.

Indicators run with PineTS. Results may differ from TradingView. Check warnings
and missing outputs, and do not treat an indicator signal as a guarantee of profit.
