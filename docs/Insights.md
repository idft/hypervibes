# Insights

Insights are lessons carried forward from previous work. Open Insights under
Memories to read them.

- View global insights for the agent.
- Select a sub-agent to read lessons specific to that worker.
- Read the latest version.
- Browse revision history for update times and reasons.

Insights are read-only in this view. A Review sub-agent manages them through
its tools. If there are no insights yet, check that a reviewer is configured
and has completed a run.

Insights guide later work. They do not change tool permissions or enforced
[trading limits](Settings.md).
