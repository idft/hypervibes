# Memories

Memories are saved research, trade decisions, and reviews. Open Memories inside
an agent to read work published by its main conversation and sub-agents.

## Find saved work

- Search memory summaries.
- Filter by kind, instrument, topic, producer, status, and date.
- Open a memory to read its summary and full contents.
- Copy its reference to mention it in chat.

## Check the evidence

- See who produced a memory and open its source run when available.
- Check the evidence time and expiry before using market research.
- Follow links to supporting material and related memories.
- Check whether a newer memory corrects or replaces it.

A saved report can be outdated or wrong. Its presence in memory does not make
it current market data.

For longer-term lessons rather than individual reports, open
[Insights](Insights.md) under Memories.
